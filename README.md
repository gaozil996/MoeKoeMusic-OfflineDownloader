# MoeKoe Music 离线下载器插件

单曲 / 歌单批量下载到本地

自带原生宿主，直接写盘，不弹保存框

## 安装

把整个仓库放进：

```
%APPDATA%\moekoemusic\extensions\
```

然后重启 MoeKoe Music，在 **设置 → 插件 → 刷新插件** 里启用。

**需要插件自带原生宿主。** 首次启动时会自动拉起，界面右下角会显示本地程序状态。

二进制已随仓库提交 —— MoeKoe 按路径加载、没有构建步骤，所以 clone 下来即可用。
